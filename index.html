คู่มือการเล่นเกม

🎯 กติกาการเล่น

  1. ต่อผังงานทางซ้าย เพื่อพาตัวละครไปถึงเป้าหมาย (🏠 💎 🤴)
  2. ผังงานทำงานจากบนลงล่างทีละกล่อง เริ่มที่ "เริ่มต้น" และจบที่ "จบ"
  3. ลากรูปร่างจากชุดเครื่องมือมาวางในกรอบผังงาน แล้วลากบล็อก ทิศทาง และ ตัวเลข ไปใส่ในสี่เหลี่ยมคำสั่ง ใส่เลขได้ กี่ก้าวก็ได้ ไม่จำกัด (ลาก 1 แล้วลาก 2 = 12) ตัวละครจะเดินตอนที่ใส่ ตัวเลข แล้ว ลากทิศทางอย่างเดียวยังไม่เดิน
  4. ใส่ผิดให้ลากบล็อกใหม่มาวางทับ หรือแตะที่ตัวเลขเพื่อลบ
  5. ห้ามเดินออกนอกกระดาน และห้ามชนสิ่งกีดขวาง (🌳 🌵 🔮) ถ้าเดินผิดทาง เกมจะหยุดและเตือนว่าผิดตรงไหน
  6. ติ๊ก "รันสดทันที" ไว้ ตัวละครจะเดินต่อจากจุดเดิมทุกครั้งที่ใส่ตัวเลขหรือวางรูปร่างใหม่ หรือกด ▶️ ทดสอบรัน เพื่อเริ่มเดินใหม่ตั้งแต่จุดเริ่มต้น

🕹️ บล็อกคำสั่งเคลื่อนที่

ขึ้น + 3
เดินขึ้นไปด้านบน 3 ก้าว
ลง + 3
เดินลงไปด้านล่าง 3 ก้าว
ซ้าย + 3
เดินไปทางซ้าย 3 ก้าว
ขวา + 3
เดินไปทางขวา 3 ก้าว

ถ้าไม่ใส่ตัวเลข จะเดิน 1 ก้าว
